## План изучения DevOps

1. Настроить Git и SSH, освоить репозитории, ветки, коммиты и Pull Request.
2. Изучить командную строку, права доступа, процессы и основы сетей.
3. Освоить контейнеризацию приложений с Docker и Docker Compose.
4. Настроить автоматические проверки и сборку в CI/CD.
5. Изучить управление конфигурацией и инфраструктуру как код.
6. Освоить сбор логов, мониторинг и диагностику приложений.

План будет уточняться по мере получения следующих лабораторных работ.
