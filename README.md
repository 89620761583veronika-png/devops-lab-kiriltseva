# Лабораторные работы по DevOps

Учебный проект для освоения Git, GitHub и основных практик DevOps. Лабораторная №0 посвящена настройке рабочего окружения, созданию репозитория и работе с ветками, коммитами и Pull Request. В лабораторной №1 изучаются Docker и контейнеризация приложений, в лабораторной №2 — настройка CI/CD для Docker-приложения, а в лабораторной №3 — мониторинг с помощью Prometheus и Grafana и безопасность локального сайта.
