# Правила участия в проекте

## Порядок внесения изменений

1. Перед началом работы обновите `main`: `git switch main`, затем `git pull --ff-only`.
2. Создайте отдельную ветку: `git switch -c feature/short-description`. Для лабораторной №0 используется ветка `develop`.
3. Вносите изменения небольшими логически связанными порциями.
4. Перед коммитом проверьте `git status`, `git diff` и `git diff --check`. После добавления файлов проверьте `git diff --cached`.
5. Давайте коммитам понятные названия, описывающие изменения. Для начальной настройки используется `Initial project setup`.
6. Отправьте ветку в GitHub и создайте Pull Request в `main`.
7. В описании Pull Request укажите цель, изменённые файлы и выполненные проверки.
8. После проверки и слияния удалите рабочую ветку в GitHub и локально.

## Требования к содержимому

- Пишите документацию на русском языке в Markdown.
- Обновляйте описание проекта при изменении его структуры.
- Не добавляйте пароли, токены, приватные SSH-ключи и локальные настройки.
- Добавляйте в отчёт только фактически выполненные действия и результаты.
- Проверяйте ссылки и команды перед отправкой изменений.
- Обсуждайте изменения уважительно и по существу.
